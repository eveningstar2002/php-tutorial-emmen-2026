# Omelette Recipe — Week 3

This is a recreation of the supplied Week 3 assignment image.

## Run

Open `index.html` directly in a browser, or run a local PHP server:

```bash
php -S localhost:8000
```

Then open http://localhost:8000.

## Notes

- The page uses the HSL colors specified in the assignment.
- The layout is responsive.
- `index.php` is included as a PHP-friendly entry point, but no PHP logic is needed for this HTML assignment.
- The supplied screenshot was used to extract the visible hero image because the original `img` folder was not included in the upload.
- The CSS expects the supplied Young Serif and Outfit font files in `fonts/`. If they are absent, the browser uses Georgia/Arial fallbacks.
